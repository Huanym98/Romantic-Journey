# Romantic-Journey

一个旅行搭子社区原型（MVP）：

- 用户在注册时填写必要个人资料（生日、MBTI、星座）与旅行偏好，后续可修改。
- 用户可发布行程帖（目的地、出发返程、预算、景点等）。
- 系统按偏好给出匹配分，并支持目的地/节奏/MBTI/星座筛选。
- 提供「喜欢 / 不喜欢 / 收藏 / 私聊意向」快捷互动，帮助沉淀偏好画像。
- 内置信用机制展示（评分、守约率、实名认证状态）。
- 提供个人主页差异化能力：旅行图片/视频分享、国家足迹、里程碑勋章。

## 本地启动

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。
