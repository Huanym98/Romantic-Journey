# Romantic-Journey

一个旅行搭子社区原型（MVP）：

- 首页参考高信息密度平台布局，已接入品牌 Logo，右上角仅展示头像与昵称。
- 新增独立注册页面 `register.html`：首次登录仅需输入昵称（不可重复）即可注册。
- 右上角账户菜单支持切换账户与注销登录；每个账户的数据按昵称独立存储。
- 个人资料（生日、MBTI、星座、技能标签含会日语/会韩语 + 旅行偏好）收纳在头像下拉面板中。
- 用户可发布行程帖（目的地、时间、预算、标签、景点、详细行程安排）。
- 行程支持点赞、发布时间展示，并支持“综合/最新/最热”排序。
- 快速匹配卡片展示头像、国家足迹、成就勋章、搭子好评（评分/评价关键词）。
- 旅行主页支持图片/视频上传：选视频可传视频，选图片可一次多图上传。
- 笔记展示创建日期与地点打卡信息，并支持删除已发布内容。

## 本地启动

```bash
python3 -m http.server 4173
```

访问：
- 首次注册：`http://localhost:4173/register.html`
- 首页：`http://localhost:4173/index.html`
