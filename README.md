# Romantic-Journey

一个旅行搭子社区原型（MVP）：

- 首页参考高信息密度平台布局，已接入品牌 Logo，右上角仅展示头像与昵称。
- 个人资料（生日、MBTI、星座、技能标签 + 旅行偏好）收纳在头像下拉面板中，点击头像可编辑。
- 用户可发布行程帖（目的地、时间、预算、标签、景点、详细行程安排）。
- 行程支持点赞、发布时间展示，并支持“综合/最新/最热”排序。
- 系统按偏好给出匹配分，并支持目的地/节奏/MBTI/星座筛选。
- 提供个人主页能力：旅行图片/视频分享、国家足迹、里程碑勋章。

## 本地启动

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。
