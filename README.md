# Romantic-Journey

一个旅行搭子社区原型（MVP）：

- 用户可配置个人旅行偏好（节奏 / 预算 / 作息 / 社交）。
- 用户可发布行程帖（目的地、出发返程、预算、景点等）。
- 系统按偏好给出匹配分，并支持目的地/节奏筛选。
- 提供「喜欢 / 不喜欢 / 收藏 / 私聊意向」快捷互动，帮助沉淀偏好画像。
- 内置信用机制展示（评分、守约率、实名认证状态）。
- 新增个人主页差异化能力：旅行图片/视频分享、国家足迹、里程碑勋章（如首次结伴、首次获赞、首次出境）。

## 本地启动

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。
